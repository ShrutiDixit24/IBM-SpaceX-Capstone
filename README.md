# IBM SpaceX Capstone Project

## Project Overview
This project analyzes historical SpaceX launch data to explore launch outcomes and landing success. It includes data preparation, exploratory analysis, interactive visualizations, and machine learning model evaluation.

## Objectives
- Explore SpaceX launch records and launch sites.
- Analyze payload mass and launch outcomes.
- Visualize launch locations using Folium.
- Build an interactive dashboard using Plotly Dash.
- Compare machine learning models for landing-success prediction.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Plotly
- Folium
- Dash
- Scikit-learn
- Jupyter Notebook

## Machine Learning Results
Four models were evaluated:

| Model | Accuracy | F1 Score |
|---|---:|---:|
| K-Nearest Neighbors | 83.33% | 88.89% |
| Decision Tree | 83.33% | 88.00% |
| Support Vector Machine | 77.78% | 85.71% |
| Logistic Regression | 77.78% | 85.71% |

K-Nearest Neighbors achieved the highest F1 score in this evaluation. These results are preliminary and should be validated with additional testing.

## Project Components
- Data cleaning and preparation
- Exploratory data analysis
- Launch-site mapping with Folium
- Interactive dashboard with Plotly Dash
- Predictive analysis and model comparison
